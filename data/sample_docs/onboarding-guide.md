# Acme Cloud onboarding guide (sample document)

New engineers receive a laptop on day one and must enable two-factor authentication before accessing any internal system. Access to the production environment is granted only after the security training is completed, which usually takes the first week.

Every new hire is paired with a mentor for the first 60 days. Mentors hold a weekly one-on-one and review the first three pull requests. The on-call rotation starts after the third month, and new engineers shadow the primary on-call engineer for two weeks before taking a shift alone.

Deployments run through the CI pipeline. Direct pushes to the main branch are blocked, and each change needs one approving review.
